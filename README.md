# GetLayers Showcase & Cinematic AI Web Templates Pack

A complete, high-fidelity clone of the **GetLayers.ai** platform architecture and its cinematic web templates, featuring 53 verified assets across 5 distinct categories:
- **10 Full-Stack Web Templates** (including *AI Studio*, *Clarix*, *Dantora*, *Prisma*, *Vesper*, *Stride*)
- **9 Interactive 3D WebGL Scenes** (*Orb*, *Epoxy Drift*, *Pinwheel Galaxy*, *Aurum Peak*, *Pixel Glass*, etc.)
- **10 Interactive Scroll-Driven Sections** (*Cards Cascade*, *Colonnade*, *Slider Spectra*, *Roadmap Ascent*, etc.)
- **12 Animated High-Res Video Backgrounds**
- **12 GLSL Shaders & Color Gradients**

## 📂 Repository Structure

```text
├── index.html            # Main Showcase Platform UI (Dark Mode, 4-col responsive grid)
├── styles.css            # Modern CSS variables, glassmorphism, glowing borders
├── data.js               # Embedded catalog data for 53 library assets
├── app.js                # Search, category filters, hover video preview, AI prompt generator
└── templates/            # Standalone production-ready source code templates
    ├── index.html        # Templates pack directory
    ├── ai-studio/        # "AI Studio — The Ultimate Engine for Business Lending" (3D glass cards)
    ├── clarix/           # "Clarix — The Clarity Your Business Has Been Missing" (Holographic tech)
    └── cards-cascade/    # "Cards Cascade" (Pure CSS 3D interactive cascading deck)
```

## 🚀 Getting Started

### Local Preview
Open `index.html` directly in any modern browser, or spin up a local HTTP server:
```bash
npx serve .
# or
python -m http.server 3000
```

### Deploy to Vercel
```bash
npx vercel --prod
```
