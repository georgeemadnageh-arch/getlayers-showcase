        Documentation
        
How to build with GetLayers

        

          

            
1. The Vibe-Coding Workflow

            
Every asset on GetLayers provides an exact AI Engineering Specification. Copy the prompt directly into Claude Code, Cursor, or Hermes Twin to produce pixel-perfect Next.js 16 and Three.js code in seconds.

          

          

            
2. Using 4K Video Backgrounds

            
Background assets are pre-rendered seamless loops. Drop them into any standard HTML5 <video autoPlay loop muted playsInline> element with an aspect-ratio container for instant Stripe/Apple caliber aesthetics.

          

          

            
3. Three.js & GLSL Shaders

            
Our 3D scenes use React Three Fiber and Three.js. Shader code uses standard WebGL 2 fragment and vertex pipelines, compatible with any modern bundler.

          

        

      

    

  


  
  

    

      
      

        MCP Integration
        
Connect GetLayers to AI Agents

        
Plug the GetLayers library directly into Claude Desktop, Cursor, or Hermes Twin via Model Context Protocol.

        
        

          

            claude_desktop_config.json
            
          

          
{
  "mcpServers": {
    "getlayers": {
      "command": "npx",
      "args": ["-y", "@getlayers/mcp-server@latest"],
      "env": {
        "GETLAYERS_API_KEY": "gl_live_partner_access"
      }
    }
  }
}

        

        
Allows Claude Code / Cursor to search 758+ templates, fetch GLSL code, and inject animations directly into your codebase.
